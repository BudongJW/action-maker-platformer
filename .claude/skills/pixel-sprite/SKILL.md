# 스프라이트 시트 (T1)

먼저 `.claude/skills/pixel-rules/SKILL.md`를 읽고 그 규칙을 따른다.

요청: $ARGUMENTS

1. 요청에서 아래 항목을 뽑는다. 없는 항목은 기본값으로 채우고, 정한 값을 작업 전에 짧은 표로 보여 준다. 기본값으로 정할 수 없는 것(어느 팩인지, 작품 규칙)만 묻는다.
   - 파일: `[src]/[이름].pix` → 출력 경로(`characters/…png`, 미리보기 4배)
   - 셀: 32x40 / 프레임: `idle_0`, `idle_1`, `walk_0`~`walk_3` + 동작 프레임
   - 생김새: 나이, 체형, 머리 모양, 옷(팔레트 키), 들고 있는 것
   - 1배 실루엣에서 읽혀야 하는 것(예: 어깨에 멘 카메라, 손에 든 등불)
   - 동작마다 바뀌는 부위와 단계(예: 베기 = 준비 → 베기 → 마무리)
2. 같은 인물의 기존 시트가 있으면 먼저 읽고 비율·색·머리 모양을 맞춘다.
3. 그린다. 애니메이션은 같은 팔레트를 쓰고 바뀌는 부위만 바꾼다. 키·어깨·머리 높이는 정한 만큼만 움직인다. 반복되는 프레임은 `base=`, `mirror=`, `shift=`로 만든다.
4. 렌더하고, 프레임을 나란히 놓은 4배 미리보기를 직접 본다. 비율이 흐트러진 프레임, 떠 있는 손·소품, 실루엣이 안 읽히는 프레임을 고친다.
5. `--check`로 확인하고, 만든 프레임 목록과 미리보기를 보여 준다.
