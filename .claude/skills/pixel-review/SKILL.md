# 렌더 뒤 셀프 검수 (R1)

먼저 `.claude/skills/pixel-rules/SKILL.md`를 읽는다.

대상: $ARGUMENTS

1. 대상이 원본이면 렌더한다. 미리보기 PNG를 직접 보고, 손·얼굴·발·소품이 닿는 곳은 잘라서 3~4배로 본다.
2. 아래를 하나씩 확인한다.
   1. 1배 크기에서 실루엣만으로 무엇인지 읽히나
   2. 광원이 한 방향인가, 명암 경계가 뚜렷한가
   3. 외톨이 픽셀, 지글거리는 디더, 외곽을 따라 같은 폭의 띠(필로우 셰이딩)
   4. 손: 손가락 넷과 엄지가 보이나, 쥔 손이 물건에 실제로 닿았나
   5. 얼굴: 표정이 지시·콘티와 맞나, 이목구비가 면 위에 놓였나
   6. 머리카락: 덩어리인가, 빗살·공·가시·새 모양이 아닌가
   7. 물건·인물이 떠 있지 않나(바닥·책상·벽에 닿음)
   8. 장면: 바닥 줄 위치, 조명 띠, 낮·밤 타일 혼용, 작품 금지 사항
3. 문제를 "위치 / 증상 / 고칠 방법" 표로 적는다. 문제가 없으면 없다고 적는다.
4. 고친다. 같은 원인이 다른 그림에도 있으면 함께 고칠지 묻는다.
5. 다시 렌더하고 전후 비교 이미지를 보여 준다. `--check`로 확인한다.
