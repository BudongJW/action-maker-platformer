# 장면 (T3)

먼저 `.claude/skills/pixel-rules/SKILL.md`를 읽고 그 규칙을 따른다. 《미방송분》 컷이면 `assets/original/mibangsong/README.md`의 콘티 규칙과 컷 대응표도 읽는다.

요청: $ARGUMENTS

1. 정할 것을 표로 보여 준다: 컷 번호와 한 줄 설명, 트랙(`2026` / `linear` / `hifi` / `1979` → `@swap`), 쓸 타일셋과 배경, 등장인물과 프레임, 소품, 조명, UI 덮개(뷰파인더·배지·자막 자리).
2. 레이어: `@layer`는 매번 0행부터 깔린다. 하늘·벽·바닥은 한 레이어에서 위에서 아래로 쓴다(바닥은 10~11행). 램프처럼 위에 겹칠 것만 별도 레이어로.
3. 인물: 32x40 인물은 y=121에 두면 발이 바닥 줄(y=160)에 닿는다. 서로 또는 대상을 보도록 `flip`. 앉은 자세는 의자·계단·마루 높이에 맞춘다.
4. 소품: 바닥·책상·벽에 닿게 놓는다. 손에 든 것과 쥔 것은 손 위치에 맞춘다.
5. 조명: 어두운 장면만 `@darkness` + `@light`. 밝은 실내와 낮 장면에는 둥근 조명을 넣지 않는다.
6. UI는 `over`로 맨 위에. 글자는 런타임이므로 자리만 둔다.
7. 렌더하고 2배 미리보기 전체와, 손·소품·발이 닿는 곳을 잘라 확대한 것을 함께 본다. 떠 있는 것, 겹침 순서, 작품 규칙 위반을 고친다.
8. `--check`로 확인하고 미리보기를 보여 준다. 컷 대응표가 있는 팩이면 표의 상태와 파일명을 갱신한다.
