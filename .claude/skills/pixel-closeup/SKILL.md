# 클로즈업·인서트 (T4)

먼저 `.claude/skills/pixel-rules/SKILL.md`와 `docs/pixel-technique.md`를 읽고 그 규칙을 따른다.

요청: $ARGUMENTS

1. 아래를 표로 정해 보여 준다. 요청에 없는 표정 항목은 콘티·대사의 감정에서 추론하고, 추론했다고 표시한다.
   - 구도: CU / MCU / ECU, 정면 / 옆얼굴 / 3/4, 고개 돌림(-1..1, +는 화면 오른쪽)
   - 표정: 눈썹 안쪽(올림·내림), 눈썹 바깥쪽, 미간(찌푸림), 위 눈꺼풀(내림 정도), 아래 눈꺼풀(올림), 시선 방향
   - 입: 닫음 / 살짝 벌림 / 말함 / 노래 / 외침 / 허밍 / 꾹 다묾, 입꼬리(올림·내림)
   - 근육과 흔적: 광대 올림, 주름(미간·이마·눈가), 눈물
   - 빛: 방향과 성격(예: 모니터 빛이 정면 아래에서)
   - 트랙 팔레트, 뷰파인더 덮개 여부(덮개가 있으면 깨끗한 판과 덮개를 씌운 판을 따로 둔다)
2. 얼굴은 행으로 찍지 않는다. 두개골과 턱 실루엣에 면(눈두덩·코·광대·턱끝)으로 음영을 내고, 이목구비를 그 위에 그린다. 고개를 돌리면 이목구비가 원통 위에서 돌아가고, 먼 쪽 귀는 가리고, 턱선도 따라 돈다.
3. 옆얼굴: 헤어라인은 이마 → 관자놀이 → 귀 앞 → 귀 뒤 → 뒷목. 눈은 쐐기 모양에 앞쪽 홍채. 벌린 입은 얼굴 안쪽 쐐기로.
4. 손이 나오면 손바닥·마디·엄지 구조로. 쥔 손은 주먹 중심을 쥔 물건 좌표에 맞추고 확대해서 겹쳤는지 확인한다.
5. 렌더하고 얼굴만 3배로 잘라 본다. 보이는 표정을 한 줄로 말하고, 1번의 지시와 다르면 고친다.
6. 기존 컷을 고친 경우 전후 비교를 만들어 보여 준다. `--check`로 확인한다.
