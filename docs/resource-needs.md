## 1. 표 읽는 법

- **우선순위**: **P0** 첫 플레이어블 프로토타입(D3) / **P1** 버티컬 슬라이스(데모 수준 한 챕터) / **P2** 출시 전.
- **상태**: **있음** / **임시**(1차안 또는 수집분으로 대체 중) / **없음**.
- **조달**: **오리지널**(`assets/original/`) / **CC0**(`assets/third_party/`, 이미 수집한 팩 또는 새로 수집) / **비공개**(재배포 불가, `assets_private/` + `SOURCES.md`) / **구매**.
